What it does

            

              An open OCR pipeline for printed Armenian, maintained by Calfa. It
              runs in two stages: a layout model finds text
              regions and their reading order, then a recognition
              model transcribes each region. Layout uses third-party generic
              detectors; recognition uses open models trained by Calfa
              (hye-calfa-n — based on Tesseract 5 — and
              paddle-calfa-tiny — based on PaddleOCRv6, both trained
              for Western, Eastern and Classical Armenian). This is the open
              release, not Calfa's premium OCR; for handwritten and complex
              documents, and structure extraction, see
              Calfa.
            

          


          

            
Configuration

            
    
              
  • Confidence — the layout detector's threshold. Lower it to catch faint / small regions on bad scans; raise it to drop noise.
    • 
              
  • Reading order — how regions are sequenced: X-Y cut (default) or, with PP-DocLayoutV3, its own Native predicted order.
    • 
              
  • Detections toggle — show or hide the region / line overlay drawn on the page.
    • 
              
  • Compare detectors — the button under the panel runs the layout detectors side by side without OCR, to inspect region quality.
    • 
            

          


          

            
Models & sources

            
    
              
  • Layout (third-party, generic) —
                DocLayout-YOLO
                and
                PP-DocLayoutV3:
                generic document-layout detectors, not Armenian-specific.
    • 
              
  • Reading order — recursive X-Y cut (a projection heuristic drawn from Portmind and updated), or PP-DocLayoutV3's own predicted order.
    • 
              
  • Recognition (open, trained by Calfa) —
                hye-calfa-n (Tesseract) and
                paddle-calfa-tiny
                (PP-OCRv6-tiny).
    • 
            

          


          

            
Command-line interface

            
The same pipeline ships as the hyocr CLI — ideal for batch & scripting.

            
Install

            
# from a local clone
pip install .

# or straight from the repo
pip install "hye-open-ocr @ git+https://github.com/calfa-co/hye-open-ocr"

            
Usage

            
# basic: writes page.txt + page.json into out/
hyocr page.png -o out/

# choose formats: text, JSON, ALTO XML, searchable PDF
hyocr scan.pdf -f txt,json,alto,pdf -o out/

# pick a generic layout detector and an open recognition model
hyocr page.png --layout paddle --recognizer tesseract

# tune region detection + Tesseract segmentation
hyocr page.jpg --yolo-conf 0.25 --region-psm 4

# open Paddle model (paddle-calfa-tiny)
hyocr page.png --recognizer paddle -f txt,json

# optional: point at a local copy instead of the auto-download
export ARMENIAN_OCR_PADDLE_REC_DIR=/path/to/hye-paddle/inference

            

              Key options: --layout {yolo,paddle},
              --recognizer {tesseract,paddle},
              --yolo-conf, --region-psm,
              -f/--formats, -o/--output-dir.
              Run hyocr --help for the full list.
